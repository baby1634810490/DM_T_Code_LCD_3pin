# ADR-0001: TSDA 全速度模式分阶段重写

## Status
Accepted

## Context
旧实现以位置模式完成寻限和正常运动，并在 MCU 侧动态修改位置模式速度限制。实机表明位置任务执行期间动态速度限制不能可靠改变当前运动。旧代码已经备份，可以重新建立控制边界。

## Decision
删除旧 TSDA App、Driver、滑台封装和相关测试文档，从 Chassis 开始按全速度模式重写。Driver 保持硬件无关，CAN 通道由任务层适配；当前使用 CAN1。实现按“零速使能、自动寻限、目标写入、速度规划”逐步交付，每一步实测通过后再继续。Chassis 完成后再增加 3Pin 板级能力。

## Consequences
每一阶段的故障范围更小，实机验证结果可以直接决定下一步。迁移期间功能暂不完整，第一阶段 `ready` 保持0，不能执行寻限或目标位置运动。
